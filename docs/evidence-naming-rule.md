# 证据导入命名规则

在“链接本地文件证据”时，系统采用以下规则自动整理证据名称：

1. 原始文件名不改。
2. 原始相对路径不改。
3. 系统按相对路径排序后生成证据编号，格式为 `E01`、`E02`、`E03`。
4. 系统自动生成“规范名称”，用于界面展示、引用绑定与文书联动。

## 规范名称生成规则

规范名称由以下部分组成：

`靠近文件的两级目录 + 文件主名`

示例：

- 原路径：`一审证据/合同材料/补充协议/01_签字页.pdf`
- 证据编号：`E01`
- 规范名称：`合同材料 - 补充协议 - 签字页`

## 清洗规则

生成规范名称时，系统会自动：

- 去掉扩展名；
- 去掉前缀中的简单序号，如 `01_`、`02-`、`(3)`；
- 去掉类似 `证据1`、`附件2` 这样的通用编号前缀；
- 将下划线整理为空格；
- 去掉重复片段。

## 设计原则

1. 可追溯：保留原始文件名和原始目录结构。
2. 可检索：名称尽量体现材料所属目录和具体内容。
3. 可引用：编号与名称稳定，便于在质证书中引用。
4. 可人工修正：导入后仍可在证据卡片中手动修改展示名称。
