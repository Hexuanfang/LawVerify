# LawVerify · 文书 AI 智能证据联动原型 v1.2

直接打开 `AI智能证据联动-交互原型-可交付版.html`，或使用 React + Vite 开发版：

```bash
npm ci
npm run dev
npm run build:standalone
```

`build:standalone` 更新同名独立 HTML。浏览器会先解析页面容器，再启动内嵌 React。

从「王某诉李某 · 民间借贷纠纷」进入。起诉状展示事实与原材料冲突、缺源、法条和类案预览。代理词展示旧法时间效力和案例联动降级。买卖合同案例展示验收事实与签收人不一致。

## v1.2 亮点

- **AI 助手**：能力条（自动路由 / 卷内 / 法条 MCP / 案例 MCP / 起草 / 改写）+ 可配置技能包；输入框高度自适应
- **多入口**：划词、右上角、顶栏、右键菜单、`⌘/Ctrl+J`、核验卡、报告页、案件记忆
- **在线编辑**：声明级 contenteditable，改后转待核验，支持局部 / 全文重核（`⌘/Ctrl+Shift+E`）
- **待办优先**：右栏按律师核验重点列红灯与待核验，不再平铺全部
- **报告页**：结论先行 + 审阅版 / 清洁版 / 案例检索报告三种导出
- **案件记忆**：办案速览 / 立场与焦点 / 时间线 / 证据地图 / 金额台账 / 风险待办
- **案例检索报告**：本文书 L3 案例一键打包 Word

核验台支持十类文书、十二种声明类型、A1–A5 / B1–B6 / C1–C7 核验维度、出处预览、证据清单对齐、材料导入。红灯及待核验项阻止审阅版与清洁版导出。黄灯可忽略并保留在报告。审阅版生成原生 DOCX 批注，清洁版包含文书正文和附页报告。

本地文件导入支持 DOCX 文书的文本、常见标题和表格，以及 TXT/Markdown 正文。案件记忆的代理立场和笔记保存在当前浏览器本地存储。核验使用演示资料、有限规则和人工复核。法条和案例随文书引用提供示例预览。产品中的实时检索由 MCP 或 CLI 提供，独立 HTML 走演示适配层（`src/utils/mcp.js`），未接真实服务。

产品文档见 `产品文档/LawVerify 产品 v1.2-PRD.md`（AI 助手规则、技能包、核验处理规则）。
