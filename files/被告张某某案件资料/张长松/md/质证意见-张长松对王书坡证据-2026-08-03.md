# 质证意见

案号：（2026）冀1082民初7275号  
案由：合伙合同纠纷  
原告：王书坡  
被告：张长松  

三河市人民法院：

被告张长松的委托诉讼代理人依据现有卷宗材料，现就原告提交的四组证据发表质证意见如下。

## 一、总体质证立场

1. 被告不否认双方曾存在口头合作炒股关系，亦不否认双方原则上约定盈利、亏损各半承担；争议在于，双方是否另有“账户亏损达到约5000元即必须卖出”的明确约定或稳定交易惯例，以及被告是否应对超过5000元的全部亏损承担赔偿责任。
2. 原告证据能够证明双方合作、案涉股票买卖及最终亏损等基础事实，但尚不足以证明“5000元固定止损规则”“被告对证券账户具有单方最终处分权”“全部扩大损失由被告一人造成”三个关键命题。
3. 原告提交的聊天记录同时包含对被告不利内容，即被告曾多次建议继续持有案涉股票。被告不回避该事实。但“提出持仓建议”与“单方强制控制账户”并非同一事实；在账户由原告持有、交易由原告执行的情况下，仍需结合双方权限约定、原告的真实意思及市场风险，判断被告建议与最终损失之间的责任关系。
4. 双方于2026年3月至5月间就退市、年底结清及按市场价格结算等事项另有聊天。该部分至少证明双方曾对案涉损失重新磋商并形成具体处理方案，足以削弱原告仅按其所称原“止损惯例”计算损失的证明力；该处理方案是否已构成合同变更或和解，应结合双方完整聊天记录、原始载体及履行情况综合认定。

## 三、逐项质证意见

### （一）对原告证据一“微信聊天记录”的质证意见

**对方证明目的：**证明双方存在口头合伙炒股关系并约定盈亏各半；双方存在约5000元止损惯例；原告多次要求卖出而被告拒绝；超过止损阈值的损失与被告行为具有直接、唯一因果关系。

**质证结论：**对能够与原始载体核对一致、主体和时间可确认的聊天及转账内容，其形式真实性原则上不持异议；对现有打印材料的完整性、语音转文字的准确性以及部分截取内容的上下文保留核验意见。对其证明双方合作及盈亏各半约定的证明目的予以认可；对其余证明目的不予认可。

1. **该证据未显示双方明确约定“亏损达到5000元即必须止损”。**现有材料中能够明确识别的核心合意是2024年1月31日关于“亏钱挣钱一人一半”“如果亏了，咱们俩一人承担一半；如果盈利也是一人一半”的沟通。原告所称“5000元止损线”未见同等明确的金额、触发条件、执行主体及违反后果约定。
2. **历史结算记录不足以形成内容确定、长期一致的5000元止损惯例。**原告材料显示，2024年3月26日“小鹏亏损4900”，次日“零跑亏损5800”，另有“铝业亏损1700”，均按五五比例结算。尤其“零跑亏损5800”已超过5000元；即便将其理解为约5000元附近止损，也只能说明个别短线交易的处理结果，尚不能证明该金额是适用于所有股票、所有持仓周期且不得变更的刚性规则。
3. **聊天内容可证明被告多次建议继续持有，但不能直接证明被告“强制”原告持仓。**2024年7月29日、8月23日、8月28日及2025年1月、2月等聊天中，被告确有“拿住吧”“等等吧”等建议，这是对被告不利的真实内容。但原告同时是其本人证券账户的持有人、资金提供者和交易执行者，现有证据未显示被告掌握账户密码、交易设备或具有绕过原告直接处分股票的权限。故该证据至多证明双方曾就持仓发生沟通且被告主张继续持有，不能据此当然推导原告丧失自主决定权。
4. **原告对风险持续知情并参与沟通，不能把最终损失简单归结为被告的单一行为。**聊天材料显示，原告能够持续查看持仓、关注股价和公司风险，并多次询问、通话；2026年5月21日又由原告自行卖出清仓。该过程说明损失形成同时涉及市场价格变化、上市公司经营及退市风险、双方投资判断、原告是否执行交易等多重因素。原告主张“直接、唯一因果关系”，尚缺少对各因素作用及损失区间的具体证明。
5. **后续结算磋商限制了原告对早期聊天的单向解释。**被告证1至证4所载2026年3月至5月聊天显示，双方曾就“退市付5万元”“未退市年底结清”“重组停牌按最近交易日结算”“正常流通按市场价格结算”等提出并确认具体方案。即使法庭最终认为尚需进一步审查其合同效力，该后续沟通也说明双方对案涉损失处理并非始终仅受原告所称5000元止损规则支配。

**证明落点：**原告证据一可以证明双方存在合作炒股关系、原则上盈亏各半，以及被告曾建议继续持有；但不足以证明存在内容明确且适用于案涉股票的5000元固定止损规则，也不足以证明被告单方控制账户或应承担超过5000元的全部损失。

### （二）对原告证据二“证券账户入金记录、持仓记录、交易流水、交割单”的质证意见

**对方证明目的：**证明资金由原告提供，案涉股票交易过程及亏损78509.27元，并证明亏损扩大与被告拒不止损具有直接因果关系。

**质证结论：**对经证券账户原始记录、完整交割单及资金流水核对一致的出资、买卖和亏损数据原则上不持异议；对仅凭截图不能核验的部分保留真实性意见。认可其与出资、持仓和亏损金额的关联性，不认可其对被告过错、因果关系及责任比例的证明目的。

1. 原告材料显示，绿景中国地产（00095.HK）于2024年5月27日买入、2026年5月21日卖出，持仓466天，实现亏损78509.27元。该类证券记录属于客观交易数据，能够证明交易结果，但其本身不记载双方内部权限、止损约定或被告的主观状态。
2. 亏损数据只能回答“亏了多少”，不能直接回答“由谁造成、按何比例承担”。从买入价0.875港元跌至卖出价0.220港元，是市场价格变化的结果；要将其中73509元全部认定为被告过错损失，原告仍需证明固定止损义务、被告具有最终卖出权限、违反义务与具体损失区间之间具有相当因果关系。
3. 原告证据显示股票最终由原告账户卖出，反而印证原告具备执行交易的现实能力。该事实并不当然免除被告可能因投资建议承担的责任，但足以否定仅凭交易流水认定被告单方控制卖出时机。
4. 原告交易记录载明亏损78509.27元，而其在2026年5月27日聊天中称亏损78502.47元，两数相差6.80元。差额虽小，仍应以证券公司完整对账单、交割单及币种换算依据核定，不能以单方概括陈述替代。

**证明落点：**该证据可证明原告出资、案涉股票持仓和实际亏损，但不能单独证明5000元止损约定、被告重大过错、损失因果关系及76009元诉请的责任计算方式。

### （三）对原告证据三“原告以往盈利分红转账记录”的质证意见

**对方证明目的：**证明双方长期履行五五分成约定，合作关系长期存续，并证明双方严格遵守小额亏损即止损的交易惯例。

**质证结论：**对经微信原始载体及支付记录核对一致的转账事实原则上无异议；认可其对长期合作及五五结算的证明作用，不认可其对5000元固定止损惯例及被告本次重大过错的证明目的。

1. 盈利分红记录能够证明“盈利如何分配”，但不能当然证明“亏损达到何金额必须卖出”。两者属于不同交易规则，后者需要能够反映止损阈值、触发方式和一贯执行的独立证据。
2. 原告提交的材料并非只有盈利分红，也包含多笔亏损结算：如亏损4400元各担2200元、亏损4900元各担2450元、零跑亏损5800元与铝业亏损1700元合计后由被告支付3750元。上述记录更直接证明历史上对实际盈亏按五五比例结算。
3. “零跑亏损5800元”超过原告主张的5000元阈值，其他交易亏损金额亦不完全一致。该材料至多反映双方过往多为短期、小额结算，不能证明存在精确、刚性且适用于案涉长期持仓股票的5000元规则。
4. 案涉股票持仓466天，与原告列举的短期交易在标的、周期、风险状态上存在明显差别。即便法庭认定过往存在“小额亏损及时处理”的一般做法，也仍需进一步证明双方已将其作为案涉股票的合同义务，以及违反后的责任承担方式。

**证明落点：**该证据能够强化双方长期合作和盈亏五五结算的事实，但不足以证明固定止损条款，亦不能据此认定被告须承担全部超额亏损。

### （四）对原告证据四“涉案股票K线走势、行情下跌记录”的质证意见

**对方证明目的：**证明股票持续下行、原告止损提议合理审慎，被告执意持仓构成重大过失。

**质证结论：**对经证券行情系统或交易所公开信息核验一致的客观价格走势原则上不持异议；认可其与股价变化和风险暴露的关联性，不认可其对被告重大过失及全部扩损责任的证明目的。

1. K线记录能够证明某一期间的开盘、收盘、成交量及价格变化，不能直接证明双方内部约定、账户控制权限及一方主观过错。
2. 股价持续下跌可以说明继续持仓具有风险，也可能成为评价双方决策审慎程度的事实基础；但以事后走势反推当时任何继续持有决定必然构成重大过失，存在结果倒推问题。仍需结合当时已公开信息、双方各自判断、原告是否明确反对及谁有权执行交易综合判断。
3. 原告材料中的公司债务、清盘呈请、移出港股通等信息，说明案涉亏损与上市公司经营和市场流动性风险存在联系。该等风险并非由被告制造，也不能仅凭行情下跌认定全部损失与被告建议之间具有唯一因果关系。
4. 如原告提交的仅为截屏或局部区间图，应当提供数据来源、查询时间和完整区间，以排除选择性展示并便于核验。

**证明落点：**该证据仅能证明股价下跌及市场风险逐步显现，不足以单独证明被告构成重大过失，更不能证明73509元全部属于应由被告赔偿的扩大损失。

## 四、原告证据体系的整体问题

### （一）“5000元固定止损规则”的证据链未闭合

原告没有提交载明该金额、触发条件、执行方式及违反后果的明确约定。历史交易金额并不完全一致，且存在实际亏损5800元后仍按五五比例结算的记录。原告从若干短线交易结果推导适用于案涉466天长期持仓的刚性规则，中间缺少稳定、一致的履行事实。

### （二）“被告建议持有”与“被告单方控制账户”之间存在推理缺口

聊天记录对被告不利之处在于其多次建议继续持有，但现有证据同时显示证券账户归原告掌握，原告持续查看行情并最终自行卖出。原告未证明被告拥有独立交易权限，亦未证明其因胁迫、欺诈或技术控制而无法卖出。故持仓建议的责任应审查，但不能等同于被告对全部交易结果承担责任。

### （三）损失与被告行为之间并非只有一种合理解释

案涉损失至少同时涉及市场价格下跌、上市公司经营及退市风险、双方投资判断、账户实际控制和卖出时点等因素。原告仅凭聊天、流水和K线，尚未完成从“被告建议持有”到“超过5000元的每一元损失均由被告单独造成”的排他性证明。

### （四）后续损失处理方案尚未被原告证据充分回应

被告证据显示，2026年3月25日后双方围绕退市付5万元、年底结清、重组停牌或正常流通时如何结算有具体沟通。该事实可能构成原约定的变更、补充或争议和解，至少属于认定现有债权内容和履行期限的重要事实。原告证据目录及证明目的没有对该后续合意的形成、效力和影响作出充分说明。

## 五、被告证据的对应证明作用

1. **被告证1、证2：**2026年3月25日、3月27日聊天，显示原告提出“退市付5万、未退市年底结清”的具体方案，被告作出回应，原告进一步确认。用于证明双方曾就案涉损失重新磋商并可能形成新的处理合意。
2. **被告证3、证4：**2026年5月19日至27日聊天，显示被告解释继续持仓与重组预期有关，并再次提出退市、重组停牌、正常流通三种结算方式。用于补充双方后期沟通全貌，反驳原告仅以早期持仓争议解释全部损失。
3. **被告证5：**2026年5月30日聊天，显示原告已经卖出股票，被告称“我没让你全卖呀”“年底呀”。用于证明原告具有并实际行使交易处分能力，以及双方对卖出时点和结算安排存在争议。

上述证据均系电子数据截图，庭审中应提交原始手机，展示账号信息、完整上下文及相关支付、交易记录；证1与证2内容高度重合，应以原始载体核对后合并说明，避免重复举证。

## 六、庭审简要质证提纲

### 对证据一

对与原始手机核对一致的聊天形式真实性原则上无异议，但不认可其关于固定5000元止损、被告强制持仓及全部扩损责任的证明目的。聊天确实显示被告多次建议继续持有，但账户由原告掌握并最终由原告卖出；记录中未见明确的5000元止损条款，历史上还存在亏损5800元后按五五结算的情况。因此，该证据只能证明双方合作、盈亏各半及持仓沟通，不能证明被告应承担全部超额亏损。

### 对证据二

对经证券公司完整对账单、交割单核实的交易及亏损数据原则上无异议，但不认可过错和因果关系的证明目的。流水只能证明亏损结果，不能证明内部止损约定、账户控制权限或责任比例；亏损78509.27元与聊天所称78502.47元尚有6.80元差异，请以完整原始记录核定。

### 对证据三

对经原始载体核对一致的转账事实无异议。该证据能够证明长期合作及盈亏五五结算，但盈利分配不能证明止损规则；其中亏损4900元、5800元及合计7500元仍按五五结算，反而说明历史结算金额并不支持精确、刚性的5000元止损主张。

### 对证据四

对可由公开行情核验的股价走势无异议，但不认可其证明被告重大过失及全部因果关系。K线只能证明市场价格下跌，不能证明双方内部约定和账户权限；公司经营、退市及流动性风险等均是损失形成因素，不能把全部亏损简单归因于被告的持仓建议。

## 七、请求法院重点核实的事项
